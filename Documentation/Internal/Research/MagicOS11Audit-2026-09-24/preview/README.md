# Aether glass — native visual concept

Три изображения в `../screenshots/` — настоящие снимки iOS Simulator, снятые командой `simctl io screenshot`. Это отдельное UIKit-приложение для визуального аудита. Оно **не подключает AetherUI** и **не является внедрённой реализацией MagicOS 11**.

## Сцены

- `proposal-components.png`: знакомый экран Components, стеклянная группа строк, выбранный сегмент, action pills, широкая floating tab bar и отдельный search.
- `proposal-chat.png`: чат, приподнятое сообщение, реакции и контекстное меню. Текст исходного выбранного сообщения не рисуется второй раз под стеклом. Положение превью и меню зафиксировано для снимка.
- `proposal-dark.png`: тот же чат в тёмной теме, стеклянный action sheet и отдельная кнопка отмены.

Композиция опирается на текущие `Resources/Screenshots/components.png` и `chat-particles.png`. Все исходные скриншоты сохранены без изменений. В каждом новом экране есть видимая маркировка `AETHER / КОНЦЕПТ`.

## Что здесь настоящее

- Публичный `UIGlassEffect` в `UIVisualEffectView`, главным образом `.clear` с небольшой тонировкой. Реакции используют `.regular` для читаемости над текстом.
- Настоящая обработка фона системным iOS glass material. Тонкие дуги на фоне помогают увидеть оптическое изменение на кромках.
- Нативные UILabel, SF Symbols, непрерывные скругления, тонкая обводка и тени; фон рисуется Core Graphics.
- Исходный код компилируется в отдельный bundle `com.aetherui.research.glassaudit20260924`. Production-файлы не затронуты.

## Что снимки не доказывают

Это зафиксированные состояния композиции. Здесь не реализованы маршрутизация AetherUI, long press, ownership/portal lifecycle, обратимый morph, прерывание жестами, столкновение меню с клавиатурой, доступность и адаптивный layout. `isInteractive` материала включён, но прикладные действия не подключены. Снимки также не подтверждают совпадение с закрытым рендерером HONOR, его оптическими параметрами или частотой кадров.

Размер сцены — 402 × 874 pt. Финальные снимки — 1206 × 2622 px (3×), iPhone 18 Pro, iOS 27.0 Simulator, Apple Silicon. Публичный материал требует iOS 26+; внешний вид на iOS 26 и физических устройствах может отличаться.

## Воспроизведение

Нужен Xcode с iOS 26+ SDK и загруженный iPhone Simulator на Apple Silicon.

```sh
./render.sh <simulator-udid>
```

Скрипт компилирует и подписывает приложение локально, устанавливает его в указанный симулятор, запускает по очереди три состояния и сохраняет PNG. Состояния выбираются аргументами запуска `components`, `chat`, `dark`. Для каждого кадра выдерживается 3 секунды после запуска. Статус-бар получает воспроизводимое время 09:41; при завершении скрипта временный override очищается. Скрипт не удаляет другие приложения и не меняет исходники AetherUI.

QA: финальные три PNG открыты и проверены визуально — текст не обрезан, панели не выходят за экран, края фона заполнены. Переходы, быстродействие и реальное поведение AetherUI этим preview не тестировались.
