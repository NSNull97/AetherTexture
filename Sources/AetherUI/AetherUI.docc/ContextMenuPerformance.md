# Context Menu Performance

Обычная презентация использует один движок source → menu. Меню сохраняет
конечный layout содержимого, а переходная оболочка управляет геометрией и
оптическим появлением. Временные snapshots принадлежат текущей презентации
и освобождаются при её завершении или отмене.

Измеряйте frame pacing на устройстве отдельно от simulator. Особое внимание
нужно длинным меню, содержимому с насыщенным фоном, быстрому повторному
открытию и закрытию до окончания появления. Размеры snapshot должны
оставаться ограниченными фактическими bounds содержимого.

`ContextMenuGlassmorphicTests` проверяет источник, appearance routing и
идемпотентное освобождение ресурсов. Проверки endpoints и lifecycle не
утверждают оптический паритет с системной записью. Для визуального сравнения
используйте фиксированный сценарий из <doc:ContextMenuMotionGuide>.
