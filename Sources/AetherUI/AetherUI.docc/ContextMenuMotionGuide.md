# Context Menu Motion

Обычное контекстное меню создаётся без выбора анимации:

```swift
let menu = ContextMenuController(
    source: .init(view: button, cornerRadius: 22),
    items: [
        .action(.init(
            id: "select",
            title: "Выбрать сообщения",
            icon: UIImage(systemName: "checkmark.circle"),
            iconSide: .leading,
            action: { _, dismiss in dismiss.dismiss() }
        ))
    ]
)
menu.present()
```

Контроллер получает appearance в момент `present()`. `appearanceStyle: nil`
следует runtime; explicit `appearanceStyle` закрепляет материал меню.
Внутренние Legacy и Glassmorphic режимы сейчас используют один движок
перехода source → menu. Пользовательский код не выбирает эти режимы и не
создаёт отдельный transition object.

Движение связывает исходную кнопку, изменение формы стекла и появление
содержимого. Исходный view передаёт визуальное представление временной
копии через source lease. Он снова получает свои alpha, transform и
interaction после dismiss, в том числе при прерванном открытии.

Для lifted preview используйте отдельную конфигурацию:

```swift
let menu = ContextMenuController(
    source: .init(view: card),
    items: items,
    preview: .init(verticalSpacing: 8, lift: 1.04)
)
```

Preview оставляет snapshot карточки либо собственный content над меню.
Параметры preview описывают расположение содержимого, а не стиль анимации.

## Воспроизводимая проверка

Example содержит экран **Components → Animation Reference** с фиксированным
фоном, коротким левым меню «Изменить» и длинным правым меню фильтров.
`--animation-reference` открывает этот экран напрямую.
`--animation-reference-autoplay` открывает его и выполняет один проход:

| Время после появления экрана | Действие |
|---|---|
| 1 s / 3 s | Открыть / закрыть левое меню. |
| 4 s / 6 s | Открыть / закрыть правое меню. |
| 6.6 s | Заменить левую кнопку аватаром. |
| 7 s / 9 s | Push со счётчиком 165 и камерой / pop. |
| 8 s | Изменить счётчик 165 → 161. |
| 11 s / 13 s | Push без правой кнопки / pop. |
| 12 s / 12.5 s | Изменить счётчик 165 → 161 → без числа. |
| 14 s | Восстановить исходные кнопки меню. |

Меню автопроигрывания получает реальный `GlassControlGroup` навигационной
панели как source. Ручные кнопки панели открывают меню через обычный
`contextMenuItemsProvider`. Кнопки в содержимом имеют стабильные
`animation-reference.*` accessibility identifiers. Обычный запуск приложения
не включает таймеры автопроигрывания.

Сравнивайте одинаковые фазы на записи устройства: предварительное
исчезновение исходного текста, основной рост, оптическое проявление строк и
остаточное движение. Полная длительность взаимодействия и длительность
основного перехода — разные измерения. Проверка модели и endpoints не
заменяет покадровое сравнение на целевой версии iOS.
